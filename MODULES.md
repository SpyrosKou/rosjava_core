# Modules

Modules marked as actively worked on are where the fork has received substantive maintenance. The remaining modules are kept compatible as test, example, benchmark, or legacy documentation modules unless noted otherwise.

- [`rosjava`](./rosjava) (`actively worked on`): core ROS 1 Java client library and the main focus of the fork.
- [`rosjava_geometry`](./rosjava_geometry) (`actively worked on`): geometry helpers built on top of `rosjava`.
- [`rosjava_helpers`](./rosjava_helpers) (`actively worked on`): helper utilities such as parameter loading.
- [`rosjava_test`](./rosjava_test) (`maintenance/support`): project test and integration support code.
- [`rosjava_tutorial_pubsub`](./rosjava_tutorial_pubsub) (`example module`): runnable publish/subscribe example.
- [`rosjava_tutorial_services`](./rosjava_tutorial_services) (`example module`): runnable service example.
- [`rosjava_tutorial_right_hand_rule`](./rosjava_tutorial_right_hand_rule) (`example module`): runnable right-hand-rule example.
- [`rosjava_benchmarks`](./rosjava_benchmarks) (`benchmark module`): benchmark applications.
- [`docs`](./docs) (`legacy module`): historical Sphinx/Javadoc build scripts and content; not the current source of truth for the fork.
